# JsonToXml
Learning project where I merge two different json formats into one xml format.

To learn more about how I approached the project you can visit the post I wrote about it:
http://tomasforsman.com/blog/2018/05/07/json-to-xml/

## Historical source

The `archive/original-prototype` branch preserves the separate four-commit
prototype history that previously existed only in an old local checkout. The
`master` branch contains the later refactored implementation.
